# Evaluation

Metrics computed from real predictions:

- Accuracy, precision, recall, F1
- Macro F1, weighted F1
- Per-class scores
- Confusion matrix
- Misclassified token list

No fabricated metrics are displayed. Empty evaluation panels mean no completed local experiment yet.

Error-analysis hints cover spelling variation, ambiguity, short tokens, OOV, normalization side effects, and context blindness of token classifiers.
